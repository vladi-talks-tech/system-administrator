Преди да навлезем по-дълбоко в конфигурирането и управлението на WIndows Server 2025, трябва да създадем лабораторна среда. И точно тук на помощ идва виртуализацията.
Виртуализацията ни позволява да стартираме виртуална машина на нашия компютър, като това ни позволява да стартираме Windows Server 2025 като приложение в операционната ни система. Можем да го стартираме, спрем, да правим снимки напълно свободно.
Идеята е, че можем да създадем безопасна, изолирана виртуална среда за учене и експериментиране, но най-важното е, че ще можем безопасно да тестваме и дори да счупим нещо, без да има риск.
Нека да започнем.
Ние изтеглихме Windows Server 2025 и сега трябва да създадем виртуална машина.

![[Pasted image 20261001115027.png]]

Избираме този, който ни е препоръчан (typical).

![[Pasted image 20261001115111.png]]

Избираме, че ще инсталираме операционната система по-късно.

![[Pasted image 20261001115151.png]]

Тук ни пита каква ще е операционната система, която ще инсталираме, затова избираме `Microsoft Windows`.

![[Pasted image 20261001115251.png]]

От падащото меню избираме Windows Server 2025.

![[Pasted image 20261001115330.png]]
