Време е да преминем през стъпките за инсталиране на Windows Server 2025. Натискаме `Power on this virtual machine`.

![[Pasted image 20261001120454.png]]

При стартиране започва обратно броене, при което трябва да натиснем някакъв клавиш на клавиатурата.
След като го направим, ще започне самия процес по инсталация.

![[Pasted image 20261001122108.png]]

Това е и процесът, който ще следваме в нормална работна среда.
Тук трябва да изберем езикът.
След това избираме начин на въвеждане. Нека да сменим на US.

![[Pasted image 20261001122405.png]]

Сега ни пита дали искаме да инсталираме Windows Server 2025 или да поправим нашия компютър. 
Ако имаме проблем с нашите файлове, например те са повредени или Windows Server има някакъв общ проблем, това може да ни помогне.
