Ако идваме от някоя от по-старите версии на Windows Server, вероятно се питаме кое е новото във 2025.
Първото нещо е, че с Windows Server 2025 можем да ъпгрейдваме до четири версии едновременно. Това означава, че можем да ъпгрейдваме директно до Windows Server 2025 от Windows Server 2012 R2 и по-нови.
Също така има нещо ново, наречено `hotpatch`. Това е налично за Windows Server 2025. Това ни позволява да прилагаме актуализации за сигурност на операционната система без нужда от рестартиране на сървъра.
